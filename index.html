📚 Module 1.1 : La Boîte Noire des LLM

🧠 Théorie : Tokenization et Embeddings

Les LLM ne "comprennent" pas le texte comme nous. Ils le transforment en une série de tokens (morceaux de mots), puis en vecteurs numériques (embeddings) dans un espace mathématique à plusieurs dimensions.

Par exemple, le mot "roi" peut être représenté par un vecteur comme [0.2, -0.5, 0.8, ..., 0.1] (en réalité, des centaines ou milliers de dimensions). Les mots proches dans cet espace ont des sens similaires : "roi" sera proche de "reine" ou "château".

Pourquoi c'est important ? Parce que c'est cette représentation qui permet aux LLM de "comprendre" les relations entre les mots, même sans conscience. C'est aussi ce qui rend leur comportement imprévisible : une petite modification dans un vecteur peut changer radicalement le résultat.
